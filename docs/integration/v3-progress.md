## M1 — Foundation

**Statistical engine** (`src/lib/engine/`): typed TypeScript port of `qda2-stats.js`, `qda2-engine.js`,
`sampling-stats.js` and `survey-stats.js`. The original `src/lib/stats.ts` is unchanged apart from exporting
`logGamma` and `gammaP`; the engine re-exports it instead of duplicating it.

Validated against external references (fixtures regenerated by scripts, never hand-edited):

| Area | Reference | Fixture / test |
| --- | --- | --- |
| Distributions, quantiles, noncentral t, power, Tukey (`ptukey`/`qtukey`) | SciPy 1.18.1 | `reference-v3.json` / `engine.test.ts` |
| Descriptives, t-tests, Welch ANOVA, Tukey HSD, Games–Howell, two-way Type I | SciPy, statsmodels 0.15.0 | same |
| OLS (HC3, leverage, Cook's D, VIF), WLS, logit | statsmodels | same |
| PCA, Cronbach's α | scikit-learn 1.9.1, direct formula | same |
| Survey: Hájek mean, linearised SE (with/without FPC), totals, domains, JK1/JKn, Rao–Scott 1st/2nd order, svyglm, post-stratification, raking and GREG weight vectors, PPS inclusion probabilities | R 4.3.3, survey 4.2.1, sampling 2.10 | `survey-reference.json` / `survey.test.ts` |

Regenerate with `python3 scripts/validation/reference.py` (also runs `reference_v3.py`) and
`Rscript scripts/validation/survey_reference.R`.

**Survey features gated in the UI** (registry `SURVEY_VALIDATION` in `survey-estimators.ts`):

- provisional: design effect (`deff`). The engine reports Kish/ratio-of-variances; R's `deff()` uses an
  SRS-with-replacement denominator that differs on small samples. The difference is tested and documented.
- unvalidated: bounded raking (different algorithm from `calibrate(bounds=)`), two-stage FPC variance
  (engine shows the ultimate-cluster approximation only), PPS variance (not implemented).
- not yet done: coverage simulations.

**Curriculum** (`src/content/curriculum/`): concepts (169), labs (20), blocks (122), course templates
(`course.qda2`, `course.survey`), question bank (41 items), datasets (5 registered), lab maturity
(`lab-status.ts`, all dimensions false until evidence exists) and reference validation (`validate.ts`:
duplicate ids, missing references, prerequisite cycles, question integrity, dataset shape and design
columns). `tests/unit/curriculum.test.ts` checks the counts, that the shipped curriculum validates with no
errors, that the validator catches injected errors, and that every question bank item that exists in
`src/content/questions.tsx` has the same option ids and correct answer.

Two question bank items keep a methodological review flag (`t-levene`, `t-output`: "Levene-first wording
contradicts the Welch-by-default guidance"). They surface as warnings, not errors.

## M2 — Lab framework and the first five labs

**Framework** (`src/components/lab/`): `shell/useLab.ts` (parameters, locks, instructions, share link,
Teach mode, EN/HU), `shell/LabShell.tsx` (title bar, Teach dialog with demo strip, aside, footer with method
and honest validation status), primitives (`ParameterControl` slider + number field, `ChoiceControl`
radiogroup, `ToggleControl`, `SeedControl`, `StatisticReadout`, `FormulaInspector`, `DecompositionBar`,
`AccessibleVisualization` = SVG + live text summary + data table, keyboard-operable `DragHandle`,
`ConceptPrompt`, `PresetBar`). Config contract in `src/lib/lab-config.ts`: the hash is
`#` + `encodeURIComponent(JSON)`; every key is coerced against `LabDefinition.params`; unknown or invalid
keys are ignored and listed to the student. The VRA lab keeps the legacy query hash (`#s=2&…`).

**Routes**: `/labs` (portfolio by family, unimplemented labs marked "Not yet available"), `/lab/<id>`
(one static route file per implemented lab; other ids 404), `/lab` keeps the original VRA lab. Prototype URLs
`/lab/sampling`, `/lab/ttest`, `/lab/ci`, `/lab/survey-weighting` redirect permanently.

## Deviations from the V3 package

| Item | Prototype | Production | Why |
| --- | --- | --- | --- |
| `twoWay` "Type I" SS | marginal SS labelled Type I | nested OLS fits (true sequential SS) | prototype values did not match statsmodels `anova_lm(typ=1)` on unbalanced data |
| `logit` log-likelihood | reported from the previous IRLS iteration | from the final coefficients | off by one iteration |
| Rao–Scott | cell-wise deff adjustment | R `svychisq` first-order "Chisq" and second-order "F" | matches R exactly |
| Replicate variance | centred on the full-sample estimate | centred on the replicate mean (`mse = FALSE`, R default); `mse` option available | matches R |
| `ds.index-120` | used for two different data sets | module 09 responses keep `ds.index-120`; generated efficacy set is `ds.efficacy-120` | ID collision |
| Dataset provenance `kind` | `"real"` used for the ESS extract | type allows `"real"` with `n: null` | ESS data are never bundled; the instructor downloads them under ESS terms |
| Survey reference script | F8 indexed `SE(svyby)` as a matrix; bounded calibrate with (0.7, 1.4) | vector indexing; bounds (0.5, 2) in `tryCatch` | the original script errors on survey 4.2.1 |
| `ci-explorer` params | `population`, `showNaive`, method `z` used by the prototype but not in the lab spec | added to `LabDefinition.params` | the hash contract only accepts declared keys |
| CI width curve | `crit·σ/√n × 2.2` for the cluster design | `t(a − 1)·√((S²_B + S̄²_W/m)/a)` from the population | the 2.2 factor was a placeholder |
| Survey Studio params | nested `design`/`mech`/`adjust` objects; flat block configs mapped `"stratified"` to an unknown type | flat params (`stage`, `shareC`, `muC`, `rho`, `covC`, `design`, `n`, `allocation`, `a`, `m`, `nonresponse`, `rate`, `slope`, `adjustment`, `showTruth`, `seed`); `"stratified"` and `"disproportionate"` handled | block configs in `blocks.ts` use the flat keys |
| Survey deff | `V_lin / ((1 − n/N)·S²/n)` (provisional) | `designEffect()` = R `svymean(deff = "replace")` paired with the no-fpc SE; `svyMean().deff` = `deff = TRUE` | now matches R; registry entry `deff` is `validated` |
| Survey Studio footer | "validated vs R survey 4.x (webR run …)" | states exactly what was checked and what was not | the prototype claim had no fixture behind it |
| Population field | 600 focusable dots | dots are decorative; a unit-id inspector and a table of sampled units are the keyboard path | 600 tab stops are unusable |
| Lazarsfeld "explanation" and "interpretation" tables | both X groups had the same Z composition, so the zero-order difference was 1.5 pp and the scenario showed replication, not explanation | compositions differ (X = 1 mostly in Z = high), zero-order d = 24.4 pp, partial d ≈ 0 | the prototype counts did not produce the pattern they were named after (caught by `lazarsfeld-lab.test.ts`) |
| ANOVA repeated measures | prototype reported uncorrected F only | `rmAnova()` adds Greenhouse–Geisser ε (capped at 1) and its p; the table shows both | the lab spec lists the sphericity correction; checked against R |
| Survey Design Studio | five flat designs (srs, strat, cluster, twostage, pps); "R survey run pending"; PPS π indexed against all PSUs while selection used frame PSUs | spec design matrix `strata` × `stages` × `pps` (so the block configs `{strata: 1, stages: 1}` and `{strata: 3, stages: 2, pps: true}` work); settlements belong to one settlement type so stratified two-stage designs are possible; validated against R | the prototype could not express the stratified PPS block config, and its R validation had not been run |
| Weighting & Calibration Lab | IPF raking with truncation for "bounded"; SE with the final weights treated as fixed; "parity with R pending" | `calibration.ts`: port of `survey:::grake` (Newton, bounds on g, `MASS::ginv`), calibration variance by residual projection as `svyrecvar`; age added as a continuous auxiliary; base weight d = N/r | truncated IPF is a different algorithm from `calibrate(bounds =)`; with only categorical auxiliaries every cell shares one g, so binding bounds were almost always infeasible; the calibration SE is what R reports |
| Complex Survey Lab | fixed `ds.trust-survey` sample, strata/cluster toggles, "R run pending" | own population so `strata`, `psuPerStratum`, `domain` ("group=C") and `model` ("y ~ x + group") from the spec and block configs work; BRR added (`survey::hadamard` matrices), JK1 declared without strata as R requires; true SE and coverage by simulation | the block configs reference variables (`group`, `x`, `y`) that the trust survey does not have; R refuses JK1 for stratified designs |
| Lazarsfeld Simpson scenario | hand-authored "Treatment A / severe case" counts | the published kidney-stone counts (Charig et al. 1986, BMJ; as discussed by Julious & Mullee 1994) | the lab spec asks for a published example; the footer says the data are published, not synthetic |
| Categorical lab | tile boundaries not draggable; `keep` param unused | boundaries draggable with keep-N or keep-margins; preset tables size the table unless `rows`/`cols` are set | lab spec interaction |
| Expected Value lab | histogram counted draws by value (two outcomes with the same x collided); E marker drawn over the x labels | counts by outcome index (`sampleDiscrete().index`); marker below the labels; `hideE` + prediction | correctness and legibility |
| Correlation & Regression, binary view | y axis relabelled 0–1 while the points stayed on the 0–100 scale | left axis y, right axis P̂(y = 1); separation is reported with what to change | the relabelled axis misread the data |

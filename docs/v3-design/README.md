# QDA2 V3 design package (reference copy)

These Markdown files are the specification and design notes that came with the QDA2 V3 prototype package
(`QDA2_ELTE_final_dev.zip`, 2026-10-23). They are kept here as **reference only**:

- The prototype runtime (`support.js`, `*.dc.html`, the `*.js` engines) is **not** in this repository. The
  production implementation lives in `src/lib/engine/`, `src/content/curriculum/` and `src/components/lab/`.
- Where these notes and the production code disagree, the code and `docs/integration/` win. Known
  corrections made during integration are listed in `docs/integration/v3-progress.md` ("Deviations").
- Validation claims in `17-validation-results.md` describe the prototype. The production validation is
  re-run by `npm run test:unit` against fixtures generated by `scripts/validation/`.
